# Réserve

App perso d'inventaire de conserves, de suivi des prix et de suggestions de recettes (PWA, sans serveur).

- `index.html` : toute l'application
- `sw.js` : fonctionnement hors ligne
- `manifest.json` + icônes : installation sur l'écran d'accueil

Données stockées sur le téléphone (localStorage). Fiches produits : Open Food Facts.
Lecture des tickets et suggestions de recettes : API Anthropic, clé saisie dans Réglages et gardée sur l'appareil.
Enseignes suivies pour la comparaison de prix : Auchan, Aldi, Carrefour, Intermarché, Monoprix, Lidl (+ Autre).
