# Réserve

App perso d'inventaire de conserves et de suivi des prix (PWA, sans serveur).

- `index.html` : toute l'application
- `sw.js` : fonctionnement hors ligne
- `manifest.json` + icônes : installation sur l'écran d'accueil

Données stockées sur le téléphone (localStorage). Fiches produits : Open Food Facts.
Lecture des tickets : API Anthropic, clé saisie dans Réglages et gardée sur l'appareil.
